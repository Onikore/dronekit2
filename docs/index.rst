=====================================
Welcome to dronekit2's documentation!
=====================================

**dronekit2** helps you create powerful apps for UAVs. These apps run on a UAV's :ref:`Companion Computer <supported-companion-computers>`, and augment the autopilot by performing tasks that are both computationally intensive and require a low-latency link (e.g. computer vision).

dronekit2 is a maintained fork of `DroneKit-Python <https://github.com/dronekit/dronekit-python>`_, which had no release since 2019. It keeps the ``dronekit`` import path and the attribute/observer API developers already know, on top of modernized packaging and internals.

This documentation provides everything you need to get started with dronekit2, including an :doc:`overview <about/overview>` of the API, quick start, guide material, a number of demos and examples,
and :doc:`API Reference <automodule>`.

.. tip::

    If you're upgrading existing code from *DroneKit-Python 2.x*, see the
    :ref:`migrating_v3` guide.

    If you're migrating from *DroneKit-Python version 1.x*, check out the older
    :ref:`Migration Guide <migrating_dkpy2_0>` (that migration predates this fork and still
    applies unchanged).
